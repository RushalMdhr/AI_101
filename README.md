# 🧠 AI Projects & Learning Journey

A collection of experiments, prototypes, and deep dives into Artificial Intelligence, LLMs, RAG systems, and practical applications. 

---

## 📂 Project Index

### 🎙️ AI Notes
**Concept:** A voice-to-text transcription tool designed to automatically write notes for students during classes.
*   **Goal:** Real-time auto-note-taking.
*   **Challenges Faced:** 
    *   *Performance:* The processing was too slow.
    *   *Architecture:* Required complex pipelines just to convert the voice data.
    *   *Language:* Needed real-time, multi-language detection which was difficult to implement seamlessly.

### 👨‍🏫 AI Tutor
**Concept:** Similar architecture to *AI Notes*, but designed to actively teach and interact with the user based on the transcribed or provided content.

### 💬 ChatBot (Local LLM Exploration)
The first major project using local LLMs. This serves as a sandbox for learning how AI bots work, focusing on context, memory, and prompt engineering.

*   **Chatbots:** Built a basic chatbot, then upgraded it with memory to understand how bots retain context and how prompt engineering shapes behavior.
*   **RAG (Retrieval-Augmented Generation):** Explored various architectures:
    *   Simple RAG system
    *   Multi-model RAG system
    *   Hybrid searches
    *   Advanced RAG pipelines

#### 🛠️ ChatBot Sub-Projects
Practical experiments built to test specific AI concepts:
*   **Embeddings:** Deep dive into how text is vectorized.
*   **Interview System:** A prototype system for conducting interviews.
*   **RAG Bots:** Re-creating simple AIs from scratch using embeddings and RAG.
*   **Daily Report Bot:** An AI designed to generate daily reports. 
    *   *Key Learning:* Discovered the practical limits of context windows and the real-world usefulness of AI for daily tasks.

### 📞 Convo AI
**Concept:** A simple bot designed for live, real-time voice conversation. 
*   **Status:** A quick prototype/test to understand the mechanics of live vocal interaction.

### ⚡ Testing Real Transcription
**Concept:** An R&D phase focused on finding the fastest, most efficient approach to voice-to-text transcription.
*   **Goal:** Match or beat the speed and accuracy of industry leaders like Google and ChatGPT.

### 📊 Evaluation Technique
**Concept:** My current area of study.
*   **Focus:** Learning how to use **LangSmith** to evaluate, track, and measure how well an LLM responds to prompts and handles tasks.
